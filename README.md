# kazAvtoJol ATS — прототип

Рабочий прототип системы приёма и отбора заявок (ATS) для kazAvtoJol: приём заявок от подрядчиков, консультантов по надзору и индивидуальных консультантов, автоматический скоринг по условиям тендера, кабинет HR для одобрения/отклонения заявок.

## Возможности

- **Кабинет заявителя** — список открытых тендеров, многошаговая форма подачи заявки с обязательной загрузкой документов, отслеживание статуса заявки
- **Кабинет HR** — дашборд с фильтром по тендерам, табличный вид, создание новых тендеров с требованиями, детальный просмотр заявки с разбивкой скоринга, одобрение/отклонение, экспорт в PDF
- **Скоринг** — прозрачная формула (специализация 40, опыт 30, документы 20, языки 10 баллов), без AI — HR видит, из чего складывается каждый балл

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Деплой

Автоматический деплой на GitHub Pages при push в ветку `main` через GitHub Actions (`.github/workflows/deploy.yml`).

---

Это прототип для демонстрации архитектуры. Данные хранятся только в памяти браузера (сбрасываются при перезагрузке страницы) — для продакшена нужен бэкенд с базой данных и файловым хранилищем для документов.
